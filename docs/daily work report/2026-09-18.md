CLI extension-list/location results. Eight additional regressions now cover

bundles and reuse without duplicate installation. The actual preview then
recognized bundled Copilot correctly. The earlier 49-check local receipt is
retained as a pre-fix checkpoint, not the final publication approval.

metacharacters before any native invocation.
